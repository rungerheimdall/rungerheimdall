Baseline

A boundary violation, at the moment it happens

The analyzer reads your layer definitions and reports the dependency before it reaches review. The same rule fails the build in CI. 

ARCH1001  'OrderService' is in layer 'Domain' but
depends on 'SqlRepository' in layer 'Infrastructure'.
Dependencies must flow inward.

Domain is the business core. It should not know
about persistence.

  1. Define IOrderRepository in Domain.
  2. Implement it in Infrastructure.
  3. Inject it at the Api layer.
